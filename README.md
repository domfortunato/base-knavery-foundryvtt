# Base Knavery

A Foundry VTT system compatible with **Knave 2e**, built for running old TSR
modules, OSE and other OSR adventures, and Knave hacks. ApplicationV2 throughout.

*Base Knavery is an independent production of Dom Bosco and is not affiliated
with Questing Beast LLC.*
